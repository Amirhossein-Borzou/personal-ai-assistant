Personal AI Assistant — Architecture

A Hermes Agent profile on a headless VPS · Telegram gateway · Google integrations · cron automation

Profile isolation

  • • Each Hermes profile = its own home directory
  • • Own config, API keys, memory, sessions
  • • Demo profile never sees production data
  • • Sessions and state stay on the VPS

Least privilege

  • • Gmail access is read-only
  • • Replies are drafted, humans send
  • • Secrets live in .env, never in the repo
  • • Approval gates for risky actions

Automation

  • • Cron jobs created from plain-text requests
  • • Script-only watchdogs wake the LLM only on threshold
  • • Results delivered straight to chat
  • • Skills let the agent extend itself
