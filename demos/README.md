# Recording demos (checklist)

All GIFs in this directory are recorded from the **isolated demo profile** with **synthetic data only**.

| File | Scenario |
|---|---|
| `calendar-briefing.gif` | Morning briefing generated from seeded Google Calendar events |
| `email-triage.gif` | Summarizing a fake inbox (read-only Gmail) |
| `cron-setup.gif` | Creating a scheduled job from plain text, alert arrives on time |
| `multi-agent.gif` | Task delegated to a spawned peer agent, result returns |
| `web-research.gif` | Cited web research |
| `watchdog-alert.gif` | Threshold watchdog alert (script-only cron) |

Before committing any recording, run through the checklist in `SETUP.md §6`.
